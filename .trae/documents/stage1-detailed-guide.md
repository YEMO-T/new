## 四、文档切块策略（按段落切分）

### 4.1 为什么按段落切分？

- 教材文档有很强的段落性
- 每个段落通常是一个完整的知识点
- 便于RAG检索时返回完整语义单元
- 避免切断知识点的完整性

### 4.2 切块规则

```python
# 切块规则说明
规则1: 以空行（连续两个换行符）作为段落分隔符
规则2: 每个段落作为一个独立的文本块
规则3: 如果段落超过800字符，则按句子再次切分
规则4: 保留段落标题，作为块的元数据
规则5: 记录每个块在原文中的页码和段落号
```

### 4.3 切块后的数据结构

```json
{
  "id": "uuid-xxx",
  "knowledge_item_id": "教材ID",
  "chunk_index": 0,
  "chunk_text": "第一单元 识字\n\n本单元学习目标：认识常用汉字50个，会写30个...",
  "source_resource": "语文_一年级上册.txt",
  "page_number": 1,
  "paragraph_number": 1,
  "vector_embedding": [0.123, 0.456, ...]  // 384维向量
}
```

## 五、具体操作步骤

### 步骤1：准备文件（你需要做的）

1. **收集教材文件**
   - 从教育部官网或出版社获取电子版教材
   - 转换为 `.txt` 格式
   - 按命名规范重命名：`学科_年级册次.txt`
   - 示例：`语文_三年级上册.txt`

2. **准备课标文件**
   - 从教育部官网下载课程标准
   - 按JSON格式整理（我提供模板）
   - 命名：`课标_学科_义务教育.json`

3. **准备题库文件**
   - 收集历年真题、练习题
   - 按JSON格式整理
   - 命名：`题库_学科_年级_类型.json`

### 步骤2：上传文件（我来帮你做）

我会创建以下工具：

1. **批量上传脚本** - 一键上传所有文件到Supabase
2. **文件格式校验脚本** - 检查文件格式是否正确
3. **数据库导入脚本** - 将文件信息录入数据库

### 步骤3：自动切块向量化（我来帮你做）

上传后，系统会自动：

1. 读取文件内容
2. 按段落切分
3. 调用向量化模型
4. 存储到pgvector

### 步骤4：测试检索效果

我会提供测试接口，你可以：

1. 输入关键词搜索
2. 查看检索结果的相关性
3. 验证RAG效果
