# 完整依赖安装命令

## 1. 安装核心依赖
npm install react-markdown remark-gfm remark-math rehype-katex katex

## 2. 安装Antd相关依赖（如果需要）
npm install antd @ant-design/cssinjs

## 3. 安装其他必要依赖
npm install lucide-react motion clsx tailwind-merge

## 4. 安装开发依赖
npm install -D @types/node typescript vite @vitejs/plugin-react tailwindcss autoprefixer

## 一键安装所有依赖
npm install react-markdown remark-gfm remark-math rehype-katex katex antd @ant-design/cssinjs lucide-react motion clsx tailwind-merge

## 如果使用pnpm
pnpm add react-markdown remark-gfm remark-math rehype-katex katex antd @ant-design/cssinjs lucide-react motion clsx tailwind-merge

## 如果使用yarn
yarn add react-markdown remark-gfm remark-math rehype-katex katex antd @ant-design/cssinjs lucide-react motion clsx tailwind-merge
